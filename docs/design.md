# 设计推导

这份文档解释参数为什么是这些值。想改音色的人应该先读它，否则很容易把某条音效调好听、却把 12 条的关系统破坏了。

## 一、只用三种原料

| 原料 | 用途 | 为什么够用 |
|---|---|---|
| 正弦叠加 `tone()` | 有音高的部分：印章的木质体、金币、铜管、标识音 | 任何有明确音高的声音都是谐波叠加 |
| 滑动正弦 `glide()` | 低频冲击、上扫 riser、下扫 whoosh | 频率滑动比静态音更容易制造"运动感" |
| 滤波噪声 `noise()` | 撞击的"咔"、掌声、风感、颗粒 | 无音高的瞬态本质上就是整形过的噪声 |

限制原料数量是有意的：12 条从同一个工具箱长出来，谐波密度和噪声质感天然接近，混在一起才像"一套"。

## 二、谐波表与音色

```js
const BELL = [[1, 1], [2.71, 0.42], [5.15, 0.16]];   // 金属 / 钟
const WOOD = [[1, 1], [2.4, 0.3], [4.1, 0.12]];      // 木质 / 印章
```

**为什么是 2.71 和 5.15，不是 2 和 3？**

整数倍频是弦和管的振动模式，听起来"和谐"。金属板、钟、锣的振动模式是非整数比的，2.71 和 5.15 接近圆形板的前几个模态比。这正是"金属感"的来源：把 2.71 换成 2.0，`logosting` 立刻从钟变成电子琴。

**木质的 2.4 / 4.1** 介于两者之间，加上 26 的快速衰减（时间常数约 38ms），听感上就是"硬物撞击 + 迅速消失"，也就是印章落在纸上的那一下。

`brass` 用的是 1~9 次谐波按 `1/(h²·0.55+1)` 衰减的锯齿近似 —— 这是铜管"亮而不刺"的折中：衰减太快会闷，太慢会像合成器 lead。

## 三、包络决定"这是什么动作"

所有 `tone()` 都是 `attack(默认 4ms) + exp(-decay·t)`。两个参数分别对应两件事：

- **attack 短 → 打击感**。4ms 是人类感知"敲击"的上限，超过 15ms 就变成"推"出来的。
- **decay 决定"重量"**。`stamp` 用 26（约 38ms），`boom` 用 3.4（约 290ms），`logosting` 的钟用 4.2~9（110~240ms）。

| 音效 | decay | 听感 |
|---|---|---|
| `tick` | 70 | 极短、点到为止 |
| `stamp` 的木质体 | 26 | 硬、干、有实体 |
| `boom` | 3.4 | 长、沉、有余震 |
| `logosting` 的 D6 | 4.2 | 钟声拖尾 |

**尾部必须收敛。** `npm test` 会检查最后 0.5% 的采样峰值 < 0.2。收不干净就会有"咔"的一声，这在批量渲染时会被 AAC 编码放大成明显的爆音。

## 四、频率与调性

`logosting` 用 A4–D5–F♯5–D6，即 **D 大调**。选 D 不选 C 的原因很实际：D 大调的三音是 F♯，比 F 更亮，在手机小喇叭上不容易糊；而且 D3（146.83Hz）做铜管根音时，泛音列落点避开了手机扬声器最差的 200–400Hz 区间。

`brass` 的和弦是 `[1, 1.26, 1.5, 2]`，即根音、近似大三度、纯五度、八度。1.26 是小三度和大三度之间的折中值 —— 故意的，因为贺报的铜管不需要真正的和声功能，需要的是"厚"。

## 五、噪声的低通系数

`noise()` 里的 `lpf` 是单极点低通，数值越接近 1 越亮：

| lpf | 截止频率（近似） | 用在哪 |
|---|---|---|
| 0.16 | ~1.2 kHz | `boom` 的气流，只留低频 |
| 0.35 | ~3 kHz | `stamp` 的房间尾，闷 |
| 0.72 | ~9 kHz | 掌声，接近真实手掌摩擦 |
| 0.9 | ~16 kHz | `tick` 的"哒"，极短 |

单极点滤波的斜率只有 6dB/oct，不够陡，所以 `noise()` 内部乘了 3.2 的补偿增益 —— 否则听起来会比设计值小 10dB。

## 六、掌声为什么不用噪声整形

用白噪声 + 包络做出来的掌声是"海浪"，不是"人"。人耳对掌声的辨识特征在**脉冲密度**上：几十只手不同步拍，形成 8~15ms 间隔的随机脉冲群，且起势比衰减快。

所以 `applause` 是 240 个随机位置、随机声像、随机长度的短噪声脉冲，密度包络在 0.18 处达到峰值再线性衰减。听感上像屋子里的 200 人，而不是录音棚里的白噪声。

## 七、时长与帧的对应

全部以 60fps 为基准设计：

| 音效 | 时长 | 帧数 | 位置约束 |
|---|---|---|---|
| `tick` | 0.10s | 6 帧 | 滚数时每 4~6 帧一次 |
| `pageflip` | 0.27s | 16 帧 | 两下翻页间隔 4.5 帧 |
| `stamp` | 0.65s | 39 帧 | 落定帧之后不能再放同重量音效 |
| `riser` | 1.23s | 74 帧 | 必须早于落定帧 1.2s 开始 |
| `applause` | 1.73s | 104 帧 | 只在高潮，且不要和 `firework` 完全重叠 |

`riser` 的末端做了硬收（最后 6% 线性归零），因为拖尾一旦撞上 `stamp`，两次冲击会粘成一坨，反而削弱落定感。

## 八、已知缺口：民族仪式音色

锣、鼓、钹、礼炮、拜年人声，是本项目唯一没有覆盖的类别，也是贺报里最"中国"的部分。

原因不是技术，是资源：没有成套的 CC0 民族打击乐。Freesound 上 QMUL 的北京京剧打击乐是 CC-BY，且是零散单条，凑不成体系。

技术上的近似路径（尚未实现）：

1. **锣**：BELL 谐波表 + 更长的 decay（12~18）+ 轻微失谐（两个振荡器间 ±3 cent 漂移）。锣的关键特征是"音高不稳"，靠失谐而不是靠加噪声。
2. **鼓**：`glide(120→55)` + `noise(lpf 0.45, decay 30)`，其实就是 `boom` 缩短版。鼓皮的"啪"是 200Hz 附近的一个快速衰减的带通噪声。
3. **钹**：6 个不相干的高频正弦（3~8kHz，随机相位）+ 极短 decay，比噪声更像金属。

想做这块，`src/presets.js` 里加一条预设即可，不需要改 DSP 层。
